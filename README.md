# RinascitaPC

Ottimizzazione completa per PC con Windows 10 e 11, portatili e fissi. Un solo file: `RinascitaPC.bat`.

## Come si usa
Scarica `RinascitaPC.bat`, fai doppio clic e rispondi Si alla richiesta di Windows. Se compare "Windows ha protetto il PC": Ulteriori informazioni > Esegui comunque.

## Cosa fa
1. Tutto in automatico (consigliato)
2. Punto di ripristino
3. Rimozione app inutili
4. Pulizia profonda del disco
5. Riparazione di Windows (DISM, SFC, antivirus)
6. Aggiornamento di app, Windows e driver
7. Programmi leggeri e gratuiti
8. Prestazioni, RAM e servizi
9. Raffreddamento e ventola
10. Ottimizzazione dischi
11. Diagnostica hardware e consigli
12. Scheda hardware
13. Verifica (sola lettura)
14. Ripara tutto: fa la verifica e sistema solo i punti che trova, riavvii compresi
15. Analisi completa del PC, hardware e software (sola lettura)

I file personali non vengono mai toccati. Prima di ogni modifica viene creato un punto di ripristino. Alla fine trovi sul Desktop un rapporto con tutto quello che e' stato fatto.

Versioni precedenti nella cartella `versioni/`.
